# Luyện thi AIL Specialist (最新人工智慧概論)

Trang luyện 130 câu trắc nghiệm (36 Đúng/Sai, 23 nhiều đáp án, 71 một đáp án) với thuật toán lặp lại ngắt quãng (biến thể SM-2 kiểu Anki).

Mở `index.html` trong trình duyệt là dùng được, không cần cài gì. Tiến độ lưu trong trình duyệt (localStorage), có thể xuất/nhập file JSON ở tab Cài đặt.

- `questions.js` – dữ liệu câu hỏi trích từ 2 file PDF đề.
- `index.html` – giao diện và thuật toán ôn tập.
